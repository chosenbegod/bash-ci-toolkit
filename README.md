# bash-ci-toolkit

Это учебная модель настоящего пайплайна на чистом bash. Принимаем путь к логу тестов аргументом. Шаг 1: Проверяем окружение. Шаг 2: Тесты. Шаг 3: Деплой. Шаги выполняются по очереди, и на первой ошибке пайплайн останавливается.

## запуск

```bash
DEPLOY_ENV=staging ./ci.sh logs/test_clear.log
```

- `DEPLOY_ENV` - окружение 
- первый аргумент - путь к логу


## Коды возврата
| Код | Значение |
|-----|----------|
| 0 | Деплой в <окружение> выполнен |
| 1 | не задана DEPLOY_ENV, и когда упали тесты |
| 2 | окружение неизвестное |
| 3 | не указан путь к логу |
